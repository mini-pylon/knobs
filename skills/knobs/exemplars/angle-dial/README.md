# angle-dial

## When

A group that places a light, sun or any direction around a point.

## What makes it good

- **Look:** 0° and the axes are labelled.
- **Look:** the angle is shown as a number.
- **Look:** the light's color is used.
- **Behaviour:** move `azimuth` and the dot circles the dial while the ball's highlight follows on the same side.

## Adapting

Keep 0° where the project's own 0° is. Angles here increase clockwise from the top. Say which way the project's angles run if that differs. Keep the dial, the number and the light's color.
